# Rencana kerja, Perbaikan UI antislop

Paket yang dikerjakan: **B** (keterbacaan), **C** (identitas visual), **D** (micro-interactions), **E** (mode gelap), plus dua item Hard Gate dari Paket A (**F-01** em dash, **F-04** angka hardcode) dan **F-03** (logo).

Dibuat otomatis tanpa tanya-jawab; setiap pilihan yang saya ambil sendiri ditulis sebagai "keputusan" di bawah.

## Keputusan yang saya ambil sendiri

- **Identitas visual (F-05, F-13):** berhenti meniru Canva. Brand tunggal = terracotta `#9a3412` (hangat, kuliner), canvas off-white hangat `#faf7f4`, ink hangat `#1c1917`. Tanpa gradien ungu→cyan, tanpa orb radial.
- **F-06:** set ikon tetap inlined (Lucide, ISC) tapi dipakai seperlunya dan tanpa `sparkles`; alasan ditulis di komponen.
- **F-03:** logo diganti wordmark teks "Boedjang" + sub-label "Voucher Studio". Tidak mengarang aset logo resmi.
- **F-11 dial MOTION:** "terkendali", 140ms umpan balik / 200ms masuk / 240ms permukaan.
- **F-17 radius:** kontrol 12px (`rounded-xl`), panel 16px (`rounded-2xl`), chip 8px (`rounded-lg`), pill `rounded-full`. `rounded-3xl` dihapus.
- **F-16 (mode gelap):** token di-override di `.dark`, tombol di sidebar, disimpan di `localStorage`, ada skrip anti-kedip di `<head>`.

## Urutan

1. `resources/css/app.css` token baru + dark + motion + keyframes.
2. `components/layouts/app.blade.php` shell: wordmark, buang "Studio Online"/titik hijau/"Pro", toggle tema, glassmorphism, kontras.
3. Komponen: `button`, `card`, `field`, `empty-state`, `status-badge`, `campaign-status-badge`, `confirm-dialog`, `toast-stack`.
4. `dashboard.blade.php` hero + hierarki stat + buang panduan 3 langkah + angka dinamis.
5. `auth/login.blade.php` em dash + orb + kontras.
6. View lain: em dash (campaigns form/index/show, templates/editor, vouchers/show, outlets/index), label slate-400, palet chart.
7. JS: `theme.js`, `counter.js`, `clipboard.js`; toasts progress bar; dialog animasi.
8. Verifikasi: `npm run build`, `php artisan test`, cek browser, Delivery Gate.
